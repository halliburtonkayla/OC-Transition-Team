# Shop illustration assets

New interior assets were generated with the built-in image-generation tool. Each request used the corresponding existing shop interior as a style/material reference: warm polished illustrated 3D, modern professional fixtures and the established shop palette. No exterior was regenerated.

## Prompt set and saved project paths

All new scenes are wide 16:9 eye-level game backgrounds, with no people, exterior, buttons or UI. Preserve the existing illustration style and realistic proportions.

| Project asset in `assets/student-businesses/rooms/` | Scene specification |
| --- | --- |
| `cool-vibes-entry-v2.webp` | Centered register ahead from the doorway, glass pastry case to the left, dining booths to the right, kitchen and supply-room doors behind; coral pink, muted teal, wood beams, plants, warm lighting. |
| `cool-vibes-kitchen.webp` | Employee baking kitchen, modern ovens/mixer/sink, stainless prep island, dry cups and clear spouted liquid jug, spoons, bowls, whisk, rolling pin, donut cutter, tongs and cooling racks. |

The `*-storefront-original.webp` files are clipped document renders of the approved exterior panels from the retained **Transition_Town_All_Storefront_References.pdf**. They preserve the original design and lettering. The original interiors remain available and are reused for pet reception/wash/supply and tire reception/bay/racks. Tool icons, movable food layers and the dog-walk map are code-native interactive graphics.
